# Java Assignments and Mini Project

This repository contains two Java programming assignments and one basic console-based mini project completed using Java.

## 📚 Assignments

### 1. Basic Calculator Program

A simple calculator program that takes two numbers as input from the user and performs basic arithmetic operations.

**Operations:**
- Addition
- Subtraction
- Multiplication
- Division

**Concepts Used:**
- Scanner
- User Input
- Switch Statement
- Conditional Statements
- Arithmetic Operators

### 2. Grade Evaluation Program

A Java program that takes a student's marks as input and evaluates the grade using conditional statements.

**Grades:**
- A
- B
- C
- Fail

**Concepts Used:**
- Scanner
- User Input
- if-else-if statements
- Conditional Logic
